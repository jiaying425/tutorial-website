
# Ye Alin (叶阿林) — Artist Portfolio

A portfolio website for Ye Alin, a distinguished contemporary Chinese painter specialising in guohua (Chinese ink painting) and the New Zhejiang-style tradition.

## Features
- Responsive design with parallax scrolling
- Gallery with category filters (Landscape, Figure, Jiangnan)
- Lightbox image viewer
- Animated timeline of career milestones
- Scroll-triggered reveal animations

## Tech Stack
- HTML5, CSS3, JavaScript
- Google Fonts (Playfair Display, Inter)
- No frameworks — pure vanilla code
